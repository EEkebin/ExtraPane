# ExtraPane artwork

`icon.png` is the original transparent, text-free two-display icon, generated for this project using imagegen. `ExtraPane.ico` contains its Windows icon sizes (16?256 px). The same icon is used by the app, tray and installers.

`banner.svg` is the editable ExtraPane wordmark banner. It embeds the exact `icon.png` used by the app, rather than a separately drawn symbol. The GitHub Pages showcase uses the same PNG unchanged. It replaces the obsolete raster banner bearing the previous name. No third-party brand mark is used.
